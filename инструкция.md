# 1) Подключаемся к серверу и обновляем систему

1. Откройте терминал на вашем компьютере.
    
2. Подключитесь к серверу по SSH (замените `user` и `server-ip` на реальные):
    

`ssh user@server-ip`

3. Обновите пакеты (берём последние версии):
    

`sudo apt update sudo apt upgrade -y`

_Что это делает:_ `apt update` скачивает список доступных обновлений, `apt upgrade` устанавливает их. Это важно, чтобы иметь последние версии системных библиотек.

---

# 2) Устанавливаем Python и pip (если не установлены)

На современных Ubuntu обычно уже есть Python3, но убедимся, установим полезные пакеты:

`sudo apt install -y python3 python3-venv python3-pip`

- `python3` — сам интерпретатор.
    
- `python3-venv` — чтобы создавать виртуальные окружения (рекомендуется).
    
- `python3-pip` — менеджер пакетов Python.
    

Проверьте версии:

`python3 --version pip3 --version`

---

# 3) Копируем файлы бота на сервер

Есть несколько вариантов: вы можете использовать `scp` (копирование по ssh), `git clone` (если проект в Git), или загрузить архив через SFTP.

**Пример: копирование с вашего ПК (scp):**  
Из локального терминала (на вашем ПК):

`scp -r /путь/к/папке_бота user@server-ip:/home/user/mybot`

_Что делает:_ копирует папку с ботом на сервер в `/home/user/mybot`.

**Если у вас Git:**

`cd ~ git clone https://github.com/yourname/your-bot-repo.git mybot`

# 4) Создаём отдельного пользователя (рекомендовано) и рабочую папку

Рекомендую не запускать бота под `root`.

Создать пользователя (если ещё нет):

`sudo adduser --disabled-password --gecos "" botuser`

Создать папку проекта и дать права:

`sudo mkdir -p /opt/mybot sudo chown botuser:botuser /opt/mybot`

Скопируйте туда файлы (через `scp` или `git` как выше) или переместите:

`sudo mv ~/mybot/* /opt/mybot/ sudo chown -R botuser:botuser /opt/mybot`

---

# 5) Создаём виртуальное окружение и устанавливаем зависимости

Вход под пользователем botuser:

`sudo -iu botuser cd /opt/mybot python3 -m venv .venv`

Активируем виртуальное окружение:

`source .venv/bin/activate`

Теперь в подсказке вы увидите `(.venv)` — это значит, что вы в окружении и все пакеты установятся локально в проект.

Сохраняем файл зависимостей (ниже я дам `requirements.txt`). После того как файл сохранён в `/opt/mybot/requirements.txt`, установите пакеты:

`pip install --upgrade pip pip install -r requirements.txt`

_Что это делает:_ устанавливает все нужные библиотеки для работы бота.

# 9) Создаём systemd-сервис (автозапуск и перезапуск)

Создайте файл `/etc/systemd/system/mybot.service` с таким содержимым (используем `botuser` и абсолютные пути):

[Unit]
Description=My Telegram Bot
After=network.target

[Service]
Type=simple
User=botuser
WorkingDirectory=/opt/mybot
Environment="PATH=/opt/mybot/.venv/bin"
Environment="PYTHONUNBUFFERED=1"
ExecStart=/opt/mybot/.venv/bin/python /opt/mybot/bot.py
Restart=on-failure
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target


Пояснения:

- `User` — под каким пользователем будет работать сервис.
    
- `WorkingDirectory` — рабочая папка.
    
- `Environment PATH` — указывает путь к виртуальному окружению, чтобы `python` был из `.venv`.
    
- `ExecStart` — точная команда для запуска бота.
    
- `Restart=on-failure` — автоматически перезапустит бот при падении.
    

После сохранения файла:

sudo systemctl daemon-reload
sudo systemctl enable mybot.service    # включить автозапуск при старте системы
sudo systemctl start mybot.service     # запустить сейчас


Проверить статус:

`sudo systemctl status mybot.service`

---

# 10) Просмотр логов

systemd пишет логи в `journalctl`. Чтобы смотреть последние строки:

`sudo journalctl -u mybot.service -f`

`-f` — следить в реальном времени (как `tail -f`). Для просмотра за период: `sudo journalctl -u mybot.service --since "2025-09-10 10:00"`.

---

# 11) Обновление кода и перезапуск сервиса

Если вы обновили файлы бота (скопировали новые), выполните:

`sudo systemctl restart mybot.service`

Если изменяли systemd-юнит, выполните:

`sudo systemctl daemon-reload sudo systemctl restart mybot.service`

# 13) Частые ошибки и как их диагностировать

- **Ошибка импорта пакета** → проверьте, что вы активировали `.venv` и что `pip install -r requirements.txt` успешно выполнился.
    
- **Падающий процесс сразу после запуска в systemd** → смотрите `journalctl -u mybot.service` — там будет traceback Python.
    
- **Бот не отвечает** → проверьте токен и интернет (сервер должен иметь исходящий доступ в интернет).
    
- **matplotlib пытается открыть графическое окно** → используйте `matplotlib.use('Agg')` как выше.
