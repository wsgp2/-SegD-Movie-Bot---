## 📋 **Функциональность**

### 🎯 **Основные возможности:**
- **✍️ Добавление фильмов** - Пошаговый диалог: название → год → рейтинг (1-10) → отзыв
- **🎬 Коллекция фильмов** - Просмотр всех фильмов с удобными inline кнопками
- **🔎 Умный поиск** - Поиск по названию фильма и содержанию отзыва
- **📊 Статистика с графиками** - Визуализация просмотров за 7/30/90/365 дней
- **📁 Экспорт в Excel** - Выгрузка всей базы для админов
- **⏰ Напоминания** - Еженедельные push-уведомления (воскресенье 18:30 МСК)
- **👑 Система админов** - Гибкое управление правами через команды

### 🎨 **Особенности интерфейса:**
- **Красивые эмодзи** и структурированные сообщения
- **Inline клавиатуры** для удобной навигации  
- **Адаптивные графики** с группировкой по дням/неделям/месяцам
- **Информация о создателе** встроена в бота

## 🚀 **Как начать**

### Для пользователей:
1. Найдите бота в Telegram по токену или имени пользователя
2. Отправьте команду `/start` 
3. Используйте кнопку **"✍️ Добавить фильм"** для добавления первого фильма
4. Изучите остальные функции через главное меню

### Для разработчиков:
```bash
git clone https://github.com/wsgp2/-SegD-Movie-Bot---.git
cd -SegD-Movie-Bot---
python -m venv venv
source venv/bin/activate  # Linux/Mac
pip install -r server_requirements.txt
python main.py
```

## 🤖 **Команды бота**

### 📱 **Пользовательские команды:**
| Команда | Описание |
|---------|----------|
| `/start` | Красивое приветствие + главное меню |
| `/stats` | Подробная статистика с автографиками |
| `/search` | Поиск фильмов по названию/отзыву |
| `/about` | Информация о создателе и заказе ботов |

### 🎛 **Кнопки главного меню:**
- **✍️ Добавить фильм** - Пошаговое добавление с рейтингом
- **🎬 Мои фильмы** - Коллекция с inline кнопками для деталей
- **🧮 Статистика** - Графики просмотров за разные периоды  
- **🔎 Поиск** - Поиск по коллекции
- **ℹ️ О боте** - Контакты создателя и заказ ботов

### 👑 **Админские команды:**
| Команда | Описание |
|---------|----------|
| `/admin` | Экспорт всей базы данных в Excel |
| `/set_admin <id>` | Добавить нового админа |
| `/unadmin <id>` | Убрать админа из списка |

## ⚙️ **Установка**

### 📋 **Требования:**
- Python 3.12+
- SQLite3
- Токен Telegram бота от [@BotFather](https://t.me/botfather)

### 🔧 **Локальная установка:**
```bash
# Клонирование репозитория
git clone https://github.com/wsgp2/-SegD-Movie-Bot---.git
cd -SegD-Movie-Bot---

# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# Установка зависимостей
pip install -r server_requirements.txt

# Настройка конфигурации
# Отредактируйте config.py - добавьте свой токен от @BotFather и ID админов

# Запуск
python main.py
```

### 🚀 **Развертывание на сервере:**
Проект готов для развертывания на любом Linux сервере с автоматическим скриптом `deploy.sh`.

## 🛠 **Технические детали**

### 📊 **Архитектура:**
- **Backend**: Python 3.12 + AsyncIO
- **База данных**: SQLite с aiosqlite
- **Telegram API**: pyTelegramBotAPI (асинхронная версия)
- **Графики**: Matplotlib с Agg backend
- **Развертывание**: Systemd + автоматические скрипты

### 📁 **Структура проекта:**
```
├── 📂 handlers/          # Обработчики сообщений и callback-ов
├── 📂 services/          # Сервисы (напоминания, графики)
├── 📂 logs/              # Логи приложения
├── 📂 tmp/               # Временные файлы
├── 🐍 main.py           # Точка входа для production
├── 🐍 bot.py            # Точка входа для разработки
├── 🗄️ db.py             # Работа с базой данных
├── ⚙️ config.py         # Конфигурация
└── 📋 server_requirements.txt  # Зависимости
```

### 🔄 **Особенности реализации:**
- **State Machine** для диалогов добавления фильмов
- **Автоматическая ротация логов** для production
- **Безопасная работа с правами** админов через БД
- **Оптимизированные SQL запросы** с поддержкой поиска
- **Graceful обработка ошибок** и восстановление
